## 🌐 Pages Overview

1. **Dashboard** (`index.html`) — Overview: active study streak, quick stats, high-priority topics, search, and quick task creation form.
2. **Subjects & Topics** (`pages/subjects.html`) — Manage subjects, course codes, target hours, and checkable topic lists.
3. **Pomodoro Timer** (`pages/timer.html`) — 25-min focus timer display, break controls, active task focus selector, timer configuration form, and manual session logger.
4. **Progress Analytics** (`pages/progress.html`) — Visual progress bars, achievement badges, date range filter, and weekly target reflections.
